# ed1
Exercícios das listas da matéria Estruturas de Dados 1, dada pelo professor Rodrigo Minetto, na UTFPR.
Aqui são abordadas as seguintes estruturas: fila, pilha, lista simplesmente e duplamente encadeada, além de um pouco de complexidade, recursão, busca binária e alguns algoritmos de ordenação: bubble, selection, insertion, quick e merge-sort.
